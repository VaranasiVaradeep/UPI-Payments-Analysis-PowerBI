# UPI Payments Analysis using Power BI

## Project Overview
This project focuses on analysing UPI payment transactions using Microsoft Power BI. The aim is to present transaction data through interactive dashboards and visualisations to make the information easier to understand.

## Tools Used
- Microsoft Power BI
- Microsoft Excel

## Project File
The Power BI project file (`.pbix`) is available in this repository.

## Objectives
- Explore UPI payment transaction data.
- Present information through charts and visualisations.
- Build an interactive dashboard for exploring transaction patterns.
- Practise data visualisation and analytical presentation using Power BI.

## Skills Demonstrated
- Data visualisation
- Dashboard development
- Data analysis
- Presenting data insights

## How to View the Project
1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the report pages and available dashboard interactions.

## Project Structure

- `power bi project on UPI payments.pbix` — Power BI report file containing the dashboard and visualisations.
- `README.md` — Project overview, tools used, objectives, and instructions for viewing the report.
